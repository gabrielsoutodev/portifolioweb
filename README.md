# Gabriel Augusto | Portfólio

Portfólio pessoal desenvolvido para apresentar meus projetos, minhas habilidades técnicas e minha evolução na área de desenvolvimento de software.

O projeto foi construído utilizando HTML5 e CSS3, com foco em um layout moderno, responsivo e de fácil navegação.

## Sobre o projeto

Este site reúne informações sobre minha trajetória acadêmica, tecnologias que estou estudando, projetos desenvolvidos e formas de contato profissional.

O objetivo é documentar minha evolução como estudante de Ciência da Computação e compartilhar meus trabalhos com a comunidade de tecnologia e recrutadores.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, layout, animações simples e responsividade.

## Funcionalidades

- Apresentação pessoal.
- Seção de projetos com descrições e tecnologias utilizadas.
- Seção de habilidades técnicas.
- Links para GitHub, LinkedIn e e-mail.
- Navegação entre seções da página.
- Layout adaptável para diferentes tamanhos de tela.
- Favicon e metadados básicos para o navegador.

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/gabrielsoutodev/portifolioweb.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd portifolioweb
   ```

3. Abra o arquivo `index.html` no navegador.

   Você também pode utilizar a extensão Live Server no Visual Studio Code para visualizar as alterações durante o desenvolvimento.
